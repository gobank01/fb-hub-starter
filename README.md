# fb-hub-starter

**เครื่องแยก 1 ตัว ทำงาน Facebook ให้คุณ 24 ชั่วโมง** — ตอบคอมเมนต์ · ตอบอินบ็อกซ์ · โพสต์ · ลงกลุ่ม

ไม่ใช้ API ไม่ใช้ token ของ Facebook — **คลิกจริงในเบราว์เซอร์ที่คุณล็อกอินไว้** เหมือนคุณนั่งทำเอง แค่ไม่ต้องนั่ง

---

## ปัญหาที่แก้

โพสต์ระเบิดที คอมเมนต์เข้ามา 1 คน/นาที ตอบมือได้ 1 คน/2 นาที — **ยิ่งไล่ยิ่งห่าง**
คนที่ไม่ได้รับการตอบ = ลีดที่หลุดมือ + ความรู้สึกโดนเมิน

## ทำไมต้อง "แยกเครื่อง"

| | |
|---|---|
| **เบราว์เซอร์ต้องเปิดค้าง** | บอทขับเบราว์เซอร์จริง ปิดโน้ตบุ๊กปุ๊บ งานหยุดปั๊บ |
| **ห้ามสองเครื่องทำพร้อมกัน** | เคยเกิดจริง — สองเครื่องตอบคนเดียวกันพร้อมกัน เกือบได้รีพลายซ้ำบนโพสต์สาธารณะ |
| **IP ต้องนิ่ง** | Facebook เห็น IP บ้านเสมอ ไม่ใช่เด้งไปมาตามที่คุณพกโน้ตบุ๊กไป |
| **คุณยังใช้เครื่องตัวเองได้** | ไม่มีหน้าต่างเด้ง ไม่มี Chrome ถูกยึด |

เครื่องอะไรก็ได้ที่เปิดค้างได้ — Mac mini มือสอง / MacBook เก่า / iMac เครื่องเดิม

## ระบบทำงานยังไง

```
ตัวจับเวลา (ทุก 30 นาที)
   └─ หย่อนไฟล์งานเข้าคิว  ~/fb-hub/jobs/
        └─ ตัวรันคิว (ล็อกไว้ ทำได้ทีละงาน)
             └─ Claude Code อ่านกฎจาก prompts/ แล้วขับ Chrome ทำจริง
                  └─ จดผลลง state/progress.log + แจ้งเตือน Telegram/LINE
```

**หัวใจอยู่ที่ `prompts/`** ไม่ใช่โค้ด — โค้ดแค่จัดคิวกับหาโพสต์ ส่วน "จะตอบว่าอะไร" อยู่ในไฟล์ข้อความที่คุณแก้เองได้

### ทำไมต้องมีคิว

Chrome มีตัวเดียว สองงานขับพร้อมกัน = หน้าเว็บโดนปิดกลางคัน งานพังทั้งคู่
ตัวรันคิวใช้ `mkdir` เป็นล็อก (atomic จริงบนทุกไฟล์ซิสเต็ม) — งานต่อแถวกันเสมอ

## มีอะไรมาให้บ้าง

| ไฟล์ | ทำอะไร |
|---|---|
| `bin/hub-run.sh` | ตัวรันคิว — หัวใจของระบบ |
| `bin/fb-watch.sh` | ตัวจับเวลา หย่อนงานเฝ้าคอมเมนต์เข้าคิว |
| `bin/chrome-bot.sh` | เปิด Chrome พร้อมพอร์ตให้บอทต่อ |
| `bin/fb-recent.js` | หาโพสต์ + Reels ของคุณใน 7 วัน แล้วจัดคิวว่ารอบนี้กวาดอันไหน |
| `bin/fb-pending.js` | สแกนว่าโพสต์ไหนมีใครยังไม่ได้ตอบ กี่คน |
| `bin/fb-status.js` | ดูสถานะคอมเมนต์ในหน้าที่เปิดอยู่ |
| `bin/notify.py` | ยิงแจ้งเตือน Telegram + LINE |
| `bin/log-push.py` | ส่งสรุปขึ้นเว็บ dashboard (ไม่ทำก็ได้) |
| `prompts/comment-watch.txt` | **กฎการตอบคอมเมนต์ทั้งหมด** ← แก้ตรงนี้ |
| `prompts/inbox-sweep.txt` | **กฎการตอบอินบ็อกซ์** ← แก้ตรงนี้ |
| `config/post-notes.tsv` | โพสต์ไหนต้องแปะลิงก์อะไร |
| `config/voice.md` | ตัวอย่างการเขียนของคุณ ให้บอทเลียนแบบ |

## เริ่มยังไง

```bash
git clone https://github.com/<คุณ>/fb-hub-starter.git
cd fb-hub-starter
bash install.sh
```

แล้วอ่าน **[SETUP.md](SETUP.md)** ทีละขั้น

**อ่าน [LESSONS.md](LESSONS.md) ก่อนเปิดใช้จริง** — เป็นบทเรียนที่เสียหายมาแล้วจริง ๆ ทุกข้อ

## ข้อควรรู้ก่อนใช้

**นี่คือการขับเบราว์เซอร์อัตโนมัติบนบัญชีคุณเอง** — Facebook ไม่ได้อนุญาตอย่างเป็นทางการ
ความเสี่ยงคือบัญชีอาจถูกจำกัด ระบบนี้ลดความเสี่ยงด้วย:

- หน่วงสุ่ม 70-170 วินาทีต่อคน (ไม่ใช่ค่าคงที่)
- จำกัดจำนวนต่อรอบ
- ข้อความไม่ซ้ำเลยสักอัน
- ไม่ยุ่งกับโพสต์คนอื่น ไม่ทักหาคนแปลกหน้า

**ใช้กับบัญชีของคุณเองเท่านั้น** ไม่ใช่เครื่องมือสแปมหรือปั่นยอด
