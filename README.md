# fb-hub-starter

**เครื่องแยก 1 ตัว ดูแล Facebook ให้คุณ 24 ชั่วโมง** — ตอบคอมเมนต์ · ตอบอินบ็อกซ์ · เก็บออเดอร์

ไม่ใช้ API ไม่ใช้ token ของ Facebook — **คลิกจริงในเบราว์เซอร์ที่คุณล็อกอินไว้** เหมือนคุณนั่งทำเอง แค่ไม่ต้องนั่ง

```
ตัวจับเวลา (ทุก 30 นาที)
   └─ หย่อนงานเข้าคิว
        └─ ตัวรันคิว (ล็อกไว้ ทำได้ทีละงาน)
             └─ Claude Code อ่านกฎจาก prompts/ แล้วขับ Chrome จริง
                  └─ จดผลลง state/progress.log + แจ้งเตือน Telegram/LINE
```

## ปัญหาที่แก้

โพสต์ระเบิดที คอมเมนต์เข้ามา 1 คน/นาที ตอบมือได้ 1 คน/2 นาที — **ยิ่งไล่ยิ่งห่าง**
คนที่ไม่ได้รับการตอบ = ลีดที่หลุดมือ + ความรู้สึกโดนเมิน

## ทำไมต้อง "แยกเครื่อง"

| | |
|---|---|
| **เบราว์เซอร์ต้องเปิดค้าง** | บอทขับเบราว์เซอร์จริง ปิดโน้ตบุ๊กปุ๊บ งานหยุดปั๊บ |
| **ห้ามสองเครื่องทำพร้อมกัน** | เคยเกิดจริง — สองเครื่องตอบคนเดียวกัน เกือบได้รีพลายซ้ำบนโพสต์สาธารณะ |
| **IP ต้องนิ่ง** | Facebook เห็น IP บ้านเสมอ ไม่ใช่เด้งไปมาตามที่คุณพกโน้ตบุ๊กไป |
| **คุณยังใช้เครื่องตัวเองได้** | ไม่มีหน้าต่างเด้ง ไม่มี Chrome ถูกยึด |

เครื่องอะไรก็ได้ที่เปิดค้างได้ — Mac mini มือสอง / MacBook เก่า / iMac เครื่องเดิม

## หัวใจอยู่ที่ `prompts/` ไม่ใช่โค้ด

โค้ดแค่**จัดคิว**กับ**หาโพสต์** ส่วน *"จะตอบว่าอะไร"* อยู่ในไฟล์ข้อความที่คุณแก้เองได้ ไม่ต้องเขียนโปรแกรม

```bash
nano ~/fb-hub/prompts/comment-watch.txt
```

แก้เสร็จ **ปิดตัวจับเวลา → ซ้อมแบบไม่ส่งจริง → ค่อยเปิด** (ดู [SOP ส่วนที่ 5](SOP.md))

## มีอะไรมาให้บ้าง

| ไฟล์ | ทำอะไร |
|---|---|
| `bin/hub-run.sh` | ตัวรันคิว — หัวใจของระบบ (ล็อกด้วย `mkdir` กันสองงานชนกัน) |
| `bin/fb-watch.sh` · `bin/fb-inbox.sh` | ตัวจับเวลา หย่อนงานเข้าคิว |
| `bin/chrome-bot.sh` | เปิด Chrome พร้อมพอร์ตให้บอทต่อ (โปรไฟล์แยก ไม่ปนกับที่คุณใช้) |
| `bin/fb-recent.js` | หาโพสต์ + Reels ใน 7 วัน แล้วจัดคิวว่ารอบนี้กวาดอันไหน |
| `bin/fb-pending.js` | สแกนว่าโพสต์ไหนมีใครยังไม่ได้ตอบ กี่คน |
| `bin/notify.py` | ยิงแจ้งเตือน Telegram + LINE |
| `prompts/comment-watch.txt` | **กฎการตอบคอมเมนต์ทั้งหมด** ← แก้ตรงนี้ |
| `prompts/inbox-sweep.txt` | **กฎการตอบอินบ็อกซ์ + เก็บออเดอร์** ← แก้ตรงนี้ |
| `config/post-notes.tsv` | โพสต์ไหนต้องแปะลิงก์อะไร (ไม่ใส่ = บอทไม่ขายอะไรเลย) |
| `config/voice.md` | ตัวอย่างการเขียนของคุณ ให้บอทเลียนแบบ |
| `dashboard/` | หน้าเว็บดู log จากมือถือ (จะทำหรือไม่ก็ได้) |

### กติกาคิวที่ฝังไว้

```
โพสต์ที่มีบรรทัดใน post-notes.tsv  →  โพสต์ใหม่ < 1 วัน  →  ที่ไม่ได้กวาดนานสุด
```
ชนโควตาแล้วยังเหลือคนค้าง → ถอนโพสต์นั้นออกจากคิว **โพสต์ที่มีคนรอไม่มีวันถูกลืม**

## ข้อควรรู้ก่อนใช้

**นี่คือการขับเบราว์เซอร์อัตโนมัติบนบัญชีคุณเอง** — Facebook ไม่ได้อนุญาตอย่างเป็นทางการ
ความเสี่ยงคือบัญชีอาจถูกจำกัด ระบบนี้ลดความเสี่ยงด้วย:

- หน่วงสุ่ม 70-170 วินาทีต่อคน (ไม่ใช่ค่าคงที่)
- จำกัดจำนวนต่อรอบ
- ข้อความไม่ซ้ำเลยสักอัน
- ไม่ยุ่งกับโพสต์คนอื่น ไม่ทักหาคนแปลกหน้า

**ใช้กับบัญชีของคุณเองเท่านั้น** ไม่ใช่เครื่องมือสแปมหรือปั่นยอด
