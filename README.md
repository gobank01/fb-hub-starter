# fb-hub-starter

**ยกงาน Facebook ทั้งหมดไปไว้อีกเครื่อง แล้วสั่งมันจากเครื่องคุณ** — ตอบคอมเมนต์ใต้โพสต์ · โพสต์ลงกลุ่ม/Reels · (ตอบอินบ็อกซ์เป็นตัวเสริม ไม่เปิดให้เอง)

ไม่ใช้ API ไม่ใช้ token ของ Facebook — **คลิกจริงในเบราว์เซอร์ที่คุณล็อกอินไว้** เหมือนคุณนั่งทำเอง แค่ไม่ต้องนั่ง

**ลง 2 ฝั่ง คำสั่งชุดเดียวกัน**

```
เครื่องคุณ                        เครื่องบอท (เปิดค้าง 24 ชม.)
─────────────                    ──────────────────────────
install-controller.sh            install.sh
      │                                │
   fbhub status  ──── ssh ────►  ตัวจับเวลา (ทุก 30 นาที)
   fbhub job "..."                     └─ หย่อนงานเข้าคิว
   fbhub screen                             └─ ตัวรันคิว (ทำทีละงาน)
                                                 └─ Claude Code อ่านกฎจาก prompts/
                                                      └─ ขับ Chrome คลิกจริง
                                                           └─ จด log + แจ้งเตือน
```

พิมพ์ `fbhub status` จากเครื่องไหนก็ได้ ผลเหมือนกัน — **ไม่ต้องจำคำสั่งสองชุด**

## 🧰 ต้องมีอะไรก่อนเริ่ม (ลงให้ครบก่อนรัน install)

### บัญชี / ของที่ต้องเตรียม

| อะไร | ทำไม | หมายเหตุ |

| **บัญชี Claude แบบเสียเงิน** (Pro หรือ Max) | สมองของบอท (Claude Code) | บอทใช้โควตาบัญชีเดียวกับที่คุณใช้เอง · Max คุ้มกว่าถ้าคอมเมนต์เยอะ |
| **บัญชี Facebook** ที่จะให้บอทตอบ | บอทล็อกอินแทนคุณในเบราว์เซอร์แยก | ไม่ใช้ API ไม่ต้องขอสิทธิ์อะไรจาก Facebook |
| **บอท Telegram** (ฟรี) | แจ้งเตือนตอนบอทพัง/ล็อกอินหลุด | สร้างกับ @BotFather ได้ token + chat id · **ไม่ตั้ง = บอทพังแล้วไม่มีใครรู้** |
| LINE OA (ไม่บังคับ) | ช่องเตือนสำรอง | ฟรีส่งได้ ~300 ข้อความ/เดือน |
| HDMI dummy plug (~100 บาท) | Mac mini ไม่มีจอ → Screen Sharing จะเล็กจิ๋ว | เฉพาะ Mac ไม่มีจอ |

### โปรแกรมบนเครื่องบอท — macOS

ลงตามลำดับ:

| # | โปรแกรม | คำสั่ง / ที่โหลด |
|---|---|---|
| 1 | **Xcode Command Line Tools** (มี git มาด้วย) | `xcode-select --install` |
| 2 | **Homebrew** | วางคำสั่งจาก [brew.sh](https://brew.sh) |
| 3 | **Node.js 20+** และ **Python 3** | `brew install node python@3.12` |
| 4 | **Google Chrome** | [google.com/chrome](https://www.google.com/chrome/) (บอทเปิดโปรไฟล์แยกของมันเอง ไม่ปนกับของคุณ) |
| 5 | **Claude Code** | `npm install -g @anthropic-ai/claude-code` แล้วพิมพ์ `claude` **ล็อกอินที่หน้าจอเครื่องจริง/Screen Sharing** (ผ่าน SSH ล็อกอินไม่ได้) |
| 6 | เปิด **Remote Login** + **Screen Sharing** | System Settings → General → Sharing |

ส่วน `playwright-core` (ตัวคุม Chrome) และ **Playwright MCP** (ให้ Claude คลิกในเว็บได้) — `install.sh` ลงให้เอง

### โปรแกรมบนเครื่องบอท — Linux (Ubuntu)

รันสคริปต์เดียวจบ ลง Chrome, Node.js 22, Python 3, zsh, git, Claude Code, จอเสมือน + VNC ให้หมด:
```bash
sudo bash bootstrap-linux.sh
```
แล้วล็อกอิน Claude ผ่าน VNC · ⚠️ VPS ราคาถูกบางเจ้าซีพียูไม่มี SSE4.2 → Claude ค้างเงียบ (สคริปต์ตรวจให้ก่อน — ดู LESSONS ข้อ 13)

### โปรแกรมบนเครื่องคุณ (เครื่องที่ใช้สั่ง)

| โปรแกรม | ทำไม |
|---|---|
| Terminal + `ssh` | มีมากับ Mac/Linux อยู่แล้ว (Windows ใช้ WSL) |
| `git` | ดึงโค้ดนี้ลงมา |
| โปรแกรมดูหน้าจอ (VNC) | Mac มี Screen Sharing ในตัว · Windows ใช้ RealVNC Viewer |
| Tailscale (ไม่บังคับ) | อยากสั่งจากนอกบ้าน — ทำทีหลังได้ |

## ปัญหาที่แก้

โพสต์ระเบิดที คอมเมนต์เข้ามา 1 คน/นาที ตอบมือได้ 1 คน/2 นาที — **ยิ่งไล่ยิ่งห่าง**
คนที่ไม่ได้รับการตอบ = ลีดที่หลุดมือ + ความรู้สึกโดนเมิน

## ทำไมต้อง "แยกเครื่อง"

| | |
|---|---|
| **เบราว์เซอร์ต้องเปิดค้าง** | บอทขับเบราว์เซอร์จริง ปิดโน้ตบุ๊กปุ๊บ งานหยุดปั๊บ |
| **ห้ามสองเครื่องทำพร้อมกัน** | เคยเกิดจริง — สองเครื่องตอบคนเดียวกัน เกือบได้รีพลายซ้ำบนโพสต์สาธารณะ |
| **IP ต้องนิ่ง** | Facebook เห็น IP บ้านเสมอ ไม่ใช่เด้งไปมาตามที่คุณพกโน้ตบุ๊กไป |
| **คุณยังใช้เครื่องตัวเองได้** | ไม่มีหน้าต่างเด้ง ไม่มี Chrome ถูกยึด |

เครื่องอะไรก็ได้ที่เปิดค้างได้ — Mac mini มือสอง / MacBook เก่า / iMac เครื่องเดิม

## หัวใจอยู่ที่ `prompts/` ไม่ใช่โค้ด

โค้ดแค่**จัดคิว**กับ**หาโพสต์** ส่วน *"จะตอบว่าอะไร"* อยู่ในไฟล์ข้อความที่คุณแก้เองได้ ไม่ต้องเขียนโปรแกรม

```bash
nano ~/fb-hub/prompts/comment-watch.txt
```

แก้เสร็จ **ปิดตัวจับเวลา → ซ้อมแบบไม่ส่งจริง → ค่อยเปิด** (ดู [SOP ส่วนที่ 5](SOP.md))

## มีอะไรมาให้บ้าง

| ไฟล์ | ทำอะไร |
|---|---|
| `bin/hub-run.sh` | ตัวรันคิว — หัวใจของระบบ (ล็อกด้วย `mkdir` กันสองงานชนกัน) |
| `bin/fb-watch.sh` | ตัวจับเวลา หย่อนงานเข้าคิวทุก 30 นาที |
| `bin/chrome-bot.sh` | เปิด Chrome พร้อมพอร์ตให้บอทต่อ (โปรไฟล์แยก ไม่ปนกับที่คุณใช้) |
| `bin/fb-recent.js` | หาโพสต์ + Reels ใน 7 วัน แล้วจัดคิวว่ารอบนี้กวาดอันไหน |
| `bin/fb-pending.js` | สแกนว่าโพสต์ไหนมีใครยังไม่ได้ตอบ กี่คน |
| `bin/fb-quota.py` | 🆕 เพดานคอมเมนต์ต่อชั่วโมง/วัน — บอทเช็กก่อนตอบทุกคน กันโดนมองว่าเป็นสแปม |
| `bin/fb-reply-check.py` | 🆕 **ด่านตรวจภาษาก่อนส่ง** — ตีกลับข้อความยาวเกิน ซ้ำของเดิม คำติดปากบอท สัญญาลอย ชวนแชท คำลงท้ายผิดเพศ |
| `bin/no-reply.js` | 🆕 ลิสต์โพสต์ห้ามตอบ (`config/no-reply.txt`) — ใส่ลิงก์แล้วบอทเลิกแตะโพสต์นั้นทันทีรอบถัดไป |
| `bin/fb-deadman.py` | 🆕 ตัวเฝ้า "งานที่ไม่เกิด" ทุก 30 นาที — บอทเงียบ/ค้าง/Chrome ดับ/ดิสก์ใกล้เต็ม = เตือน |
| `bin/notify.py` · `bin/notify-once.py` | ยิงแจ้งเตือน Telegram (+ LINE) · ตัว once กันเตือนเรื่องเดิมซ้ำเกิน 1 ครั้ง/6 ชม. |
| `bin/load-env.sh` · `bin/render-prompt.sh` | โหลด `.env` + แทนค่าลงพรอมต์ตอนสร้างงาน |
| `bin/fbhub` | **คำสั่งเดียวคุมทุกอย่าง ใช้ได้ทั้งสองฝั่ง** — บนเครื่องคุณมันส่งต่อผ่าน ssh ให้เอง |
| `install-controller.sh` | ลงฝั่งคนสั่ง (บนเครื่องคุณ) — สแกนหาเครื่องบอทให้ด้วย |
| `bin/fb-group-post.js` | โพสต์คลิป + แคปชั่นลงกลุ่ม (มีด่านตรวจก่อนกดโพสต์) |
| `bin/fb-reel-post.js` | โพสต์ Reel ลงโปรไฟล์ทันที |
| `bin/fb-reel-schedule.js` | ตั้งเวลาโพสต์ Reel |
| `bin/fb-group-rules.js` | ดึงกฎกลุ่มหลายกลุ่มรวดเดียว — เช็คก่อนว่ากลุ่มไหนโพสต์ขายได้ |
| `bin/cdp-*.js` | คลิก/พิมพ์/อัปโหลด ด้วย event จริงระดับเบราว์เซอร์ |
| `prompts/comment-watch.txt` | **กฎการตอบคอมเมนต์ทั้งหมด** ← แก้ตรงนี้ |
| `config/post-notes.tsv` | โพสต์ไหนต้องแปะลิงก์อะไร (ไม่ใส่ = บอทไม่ขายอะไรเลย) |
| `config/voice.md` | น้ำเสียงของคุณ ให้บอทเลียนแบบ |
| `config/no-reply.txt` | 🆕 โพสต์ที่ห้ามตอบ |
| `config/banned-words.txt` | 🆕 คำที่ห้ามบอทใช้ (ธุรกิจคุณเอง) |
| `config/optional/` | ตัวตอบอินบ็อกซ์ — ไม่ติดตั้งให้ อ่าน README ในนั้นก่อนเปิด |
| `dashboard/` | หน้าเว็บดู log จากมือถือ — **ของเสริม ไม่ทำก็ได้** ตั้งค่าด้วย `fbhub dashboard` |

### กติกาคิวที่ฝังไว้

```
โพสต์ใหม่ < 1 วัน  →  ที่ไม่ได้กวาดนานสุด  →  โพสต์ใน post-notes.tsv (ไม่เกินครึ่งรอบ ไว้ท้ายรอบ)
โพสต์ใน no-reply.txt = ไม่หยิบเลย
```
ชนโควตาแล้วยังเหลือคนค้าง → ถอนโพสต์นั้นออกจากคิว **โพสต์ที่มีคนรอไม่มีวันถูกลืม**

## 🆕 อัปเดต พ.ย. 2569 — ยกบทเรียน 3 เดือนจากระบบจริงมาใส่

ระบบต้นแบบตอบคอมเมนต์จริงไปแล้วกว่า 2,700 อัน (ส.ค.–ต.ค. 69) อัปเดตนี้เอาสิ่งที่พิสูจน์แล้วมาใส่ตัวแจก:

| อะไร | ทำไม |
|---|---|
| ด่านตรวจภาษา `fb-reply-check.py` | AI ลอกประโยคตัวอย่าง/ติดคำซ้ำ — หลังมีด่าน ความยาวจาก ~230 เหลือ ~75 ตัว ขึ้นต้นไม่ซ้ำ 94–96% |
| เลิก "เดี๋ยวเจ้าของมาตอบ" | เจ้าของไม่ได้ตามมาตอบทุกอัน คนรอเก้อ — ตอบได้ตอบเลย ไม่ได้ก็ตอบกลาง ๆ ที่จบในตัว |
| เพดานต่อชั่วโมง `fb-quota.py` | กันโดนแบน · ไม่นับบรรทัดสรุปรอบเป็นการส่ง (บั๊กเดิมทำโควตาเต็มหลอกตอนโพสต์ระเบิด) |
| ลิสต์ห้ามตอบ `no-reply.txt` | สั่งหยุดด่วนรายโพสต์ได้ทันที ไม่ต้องปิดทั้งบอท |
| ตัวเฝ้า `fb-deadman.py` | บอทเคยส่ง 0 คอมเมนต์ 49 ชม. โดยไม่มี error สักตัว |
| แจ้งเตือนกันซ้ำ | เคยยิงเรื่องเดียว 294 ครั้ง จนคนปิดเสียง |
| `notify.py` เขียนใหม่ | ตัวเดิมเรียกไฟล์ที่ไม่มีในรีโป → **แจ้งเตือนไม่เคยถึงใคร** · ตัดข้อความไทยกลางตัวไม่พังแล้ว |
| คิวโพสต์แก้ 2 บั๊ก | `--pick 3` เคยทำให้ดูแค่ 3 วัน · โพสต์ post-notes เยอะเคยกินทุกช่อง โพสต์ปกติไม่ถูกกวาดเลย |
| Claude ใช้ Sonnet + ห้ามแตกเอเจนต์ย่อย | ประหยัดโควตาบัญชี Claude มาก (บอทใช้บัญชีเดียวกับคุณ) |
| ลง Playwright MCP ให้ใน install | ตัวเดิมไม่ได้ลง → Claude ไม่มีมือคลิกเว็บ |
| อินบ็อกซ์ไม่เปิดให้อัตโนมัติ | ย้ายไป `config/optional/` |

ใช้ของเดิมอยู่แล้ว อัปเดตยังไง:
```bash
cd fb-hub-starter && git pull && bash install.sh      # ไม่ทับ .env / config ที่คุณแก้ไว้
```
แล้วเติมค่าใหม่ใน `~/fb-hub/.env` (ดู `.env.example`: `MAX_PER_HOUR` `REPLY_PARTICLE` `CLAUDE_MODEL`) · ถ้าเคยเปิดอินบ็อกซ์ไว้ มันยังเปิดอยู่ ปิดด้วย `launchctl unload ~/Library/LaunchAgents/com.fbhub.fbinbox.plist`

## เริ่มยังไง

**บนเครื่องบอท** (เครื่องที่จะเปิดค้าง):
```bash
git clone https://github.com/gobank01/fb-hub-starter.git
cd fb-hub-starter && bash install.sh
```

**บนเครื่องคุณ** (ที่จะใช้สั่ง):
```bash
git clone https://github.com/gobank01/fb-hub-starter.git
cd fb-hub-starter && bash install-controller.sh
```
มันจะสแกนหาเครื่องบอทในวงแลนให้ แล้วถามว่าจะคุมเครื่องไหน

แล้วเปิด **[SOP.md](SOP.md)** ติ๊กไปทีละข้อ

### คำสั่งที่ใช้ทุกวัน (ใช้ได้จากทั้งสองเครื่อง)

```bash
fbhub status                          # เปิดอยู่ไหม · Chrome พร้อมไหม · ตอบไปกี่คนวันนี้
fbhub off                             # หยุดทันที
fbhub dry                             # ซ้อมแบบไม่ส่งจริง
fbhub job "ไปตอบคอมเมนต์โพสต์ https://... หน่อย"    # สั่งงานเป็นภาษาไทย
fbhub result <job-id>                 # ดูผลงานที่สั่งไป
fbhub screen                          # เปิดหน้าจอเครื่องบอท
```

> `fbhub job` หย่อนไฟล์งานเข้าคิวแล้วให้ Claude Code บนเครื่องนั้นทำ
> **สั่งผ่าน ssh ตรง ๆ ไม่ได้** — Claude อ่าน Keychain ผ่าน ssh ไม่ถึง ต้องผ่านคิวเท่านั้น

ความเสี่ยงคือบัญชีอาจถูกจำกัด ระบบนี้ลดความเสี่ยงด้วย:

- หน่วงสุ่ม 70-170 วินาทีต่อคน (ไม่ใช่ค่าคงที่)
- จำกัดจำนวนต่อรอบ
- ข้อความไม่ซ้ำเลยสักอัน
- ไม่ยุ่งกับโพสต์คนอื่น ไม่ทักหาคนแปลกหน้า

**ใช้กับบัญชีของคุณเองเท่านั้น** ไม่ใช่เครื่องมือสแปมหรือปั่นยอด
