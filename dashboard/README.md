# dashboard — ดู log จากมือถือ

**ไม่ทำก็ได้** ระบบหลักทำงานได้โดยไม่ต้องมีหน้านี้ (`tail ~/fb-hub/state/progress.log` ก็พอ)

## ทำไมเครื่องต้องเป็นฝ่ายยิงออก

เครื่องที่บ้านอยู่หลังเราเตอร์ — เว็บข้างนอกเข้าถึงตรง ๆ ไม่ได้
→ **เครื่องยิงสรุปออกไปเอง** ทุก 5 นาที ไม่ใช่เว็บมาดึง

```
เครื่องคุณ (com.fbhub.logpush ทุก 5 นาที)
  └─ log-push.py  อ่าน progress.log + ผลงานแต่ละรอบ
       └─ POST /api/push  (มี secret กัน)
            └─ Postgres (แถวเดียว ทับไปเรื่อย ๆ)
                 └─ หน้าเว็บ รีเฟรชเอง 60 วิ
```

## ติดตั้ง

1. สมัคร [Neon](https://neon.tech) (ฟรี) สร้าง database เอา connection string มา
2. deploy โฟลเดอร์นี้ขึ้น [Vercel](https://vercel.com)
3. ตั้ง environment variable บน Vercel:
   - `DATABASE_URL` = connection string จาก Neon
   - `PUSH_SECRET` = สุ่มมาเอง (`openssl rand -hex 16`)
4. ใส่ค่าเดียวกันลง `~/fb-hub/.env`:
   ```
   DASHBOARD_URL=https://<ของคุณ>.vercel.app
   FB_LOG_SECRET=<PUSH_SECRET ตัวเดียวกัน>
   ```
5. ยิงลองทันที:
   ```bash
   set -a; source ~/fb-hub/.env; set +a; python3 ~/fb-hub/bin/log-push.py
   ```

## หน้าเว็บบอกอะไร

- **แถบความสด** 🟢 ≤15 นาที · 🟡 ≤1 ชม. · 🔴 เครื่องหยุดยิงแล้ว ← สำคัญสุด
- ตอบไปวันนี้กี่คน · คิวเหลือกี่งาน · กำลังทำอะไรอยู่
- ตารางว่าตอบใครไปบ้าง + ลิงก์ไปโพสต์นั้น
- รายงานเต็มของแต่ละรอบ (กดขยาย)

แถบความสดคือหัวใจ — ถ้าเครื่องดับ หน้าเว็บต้องขึ้นแดง **ไม่ใช่โชว์ข้อมูลเก่าให้เข้าใจผิดว่ายังทำงานอยู่**

## หมายเหตุ
